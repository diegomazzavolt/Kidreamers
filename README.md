# Kidreamers 📚

Uma plataforma de leitura interativa e aprendizado de idiomas de alto desempenho, projetada para tornar a aquisição de vocabulário natural e divertida através de histórias envolventes e repetição espaçada.

## 🚀 Tecnologias

- **React 19**: Base da aplicação para uma interface reativa e performática.
- **Vite**: Build system ultra-rápido.
- **Tailwind CSS 4.0**: Estilização moderna com variáveis CSS nativas e temas dinâmicos.
- **Framer Motion**: Animações fluidas, transições de página e feedback visual (delighters).
- **SM-2 Algorithm**: Lógica de repetição espaçada (Spaced Repetition System) para memorização de longo prazo.
- **Gemini API**: Integração com IA para tradução contextual e adaptação de nível CEFR (simulado).
- **Web Speech API**: Text-to-Speech integrado para prática de escuta e pronúncia.

## ✨ Funcionalidades Principais

### 1. Leitor Interativo
- **Tokenização de Texto**: Cada palavra é clicável, permitindo tradução instantânea.
- **Tradução Contextual**: Popups flutuantes com traduções baseadas no idioma de preferência.
- **Adaptação de Nível**: Reescrita dinâmica do texto para diferentes níveis CEFR (A1 a C1).
- **Audio Player**: Ouça a história completa ou palavras individuais para praticar a pronúncia.

### 2. Sistema de Baralho (SRS)
- **Algoritmo SM-2**: Gerenciamento inteligente de revisões baseado no seu desempenho.
- **Flashcards 3D**: Interface de revisão com animação de flip e botões de feedback (Again, Good, Easy).
- **Dashboard de Progresso**: Visualize quantos cards você tem para revisar hoje.

### 3. Personalização e Imersão
- **Temas Dinâmicos**: Suporte total para os modos **Light**, **Dark** e **Sepia** (focado em leitura).
- **Internacionalização**: Interface disponível em 5 idiomas (PT, EN, ES, FR, DE).
- **Skeleton Screens**: Carregamento suave de conteúdo para evitar saltos visuais.

### 4. Criação de Conteúdo
- **Envio de Histórias**: Adicione seus próprios textos à biblioteca local para estudar com o leitor interativo.

## 🛠️ Como Executar

1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Configure sua `GEMINI_API_KEY` no arquivo `.env`.
4. Inicie o servidor de desenvolvimento: `npm run dev`.
